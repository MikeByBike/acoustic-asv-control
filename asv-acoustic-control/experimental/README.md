# Experimental scripts (written, not used in the trials)

- `delphis_ping_log.py` pings a modem on a timer and logs the result to a CSV file.
- `frame_test.py` sends one small supervised test goal to the platform. It needs ROS 2 and the lab's
  topics, and it was written to settle a question about the goal frame that was never tested on hardware.

Neither script was run on the real equipment. Read them before using them.
